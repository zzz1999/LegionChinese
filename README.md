# TauriChinese

为 Tauri《魔兽世界》军团再临 **7.3.5** 玩家提供任务、NPC 对话和书籍的中文阅读体验。

**版本：1.1.4** · 离线使用 · 无需翻译密钥 · 简体优先，繁体补充

**[下载最新版](https://github.com/zzz1999/TauriChinese/releases/latest/download/TauriChinese-latest.zip)** · [查看版本记录](https://github.com/zzz1999/TauriChinese/releases) · [反馈问题与建议](https://github.com/zzz1999/TauriChinese/issues)

## 可以翻译哪些内容？

- **任务**：原版任务窗口、任务日志中的标题、正文、目标，以及进行中和交任务时的对话。
- **NPC 对话**：原版对话窗口中的文字和选项。
- **书籍与信件**：原版阅读窗口中的书页正文。

已有简体或繁体中文保持原样；需要翻译的内容优先显示简体中文，没有可用简体时使用繁体，两者都没有时保留原文。标题和正文分别处理，因此中文标题下的英文正文也可以翻译。

译文随插件一起安装，无需联网翻译或申请 API 密钥。安装包自带中文字体，英文客户端也能显示替换后的中文。

## 安装与更新

1. **退出游戏**，下载上方的 `TauriChinese-latest.zip` 安装包。
2. 解压，将里面的 `TauriChinese` 文件夹放入游戏目录的 `Interface\AddOns\`。
3. 确认文件路径如下，避免多套一层文件夹：

   ```text
   魔兽世界游戏目录
   └─ Interface
      └─ AddOns
         └─ TauriChinese
            └─ TauriChinese.toc
   ```

4. 重新启动游戏，在角色选择界面的“插件”列表中勾选 **TauriChinese**。请停用 TauriHun 等同类文本替换插件，避免互相覆盖。
5. 进入游戏即可使用，**首次安装默认开启汉化**。

更新时退出游戏，用新安装包中的 `TauriChinese` 文件夹替换旧文件夹，再重新启动游戏。插件会保留之前的开关设置；如果以前手动关闭过，输入 `/tcn on` 即可重新开启。无需删除 `WTF` 文件夹。

请下载上面的插件安装包；GitHub 自动提供的 `Source code` 压缩包是项目源码，不能直接作为插件目录安装。

## 常用命令

在游戏聊天框中输入：

| 命令 | 用途 |
|---|---|
| `/tcn` | 查看当前汉化状态和命令提示 |
| `/tcn on` | 开启汉化 |
| `/tcn off` | 关闭汉化 |
| `/tcn about` | 查看插件版本、作者和反馈地址 |

切换开关后，关闭并重新打开当前任务、对话或书籍窗口。

首次进入游戏时会弹出介绍窗口，同一游戏账号只自动显示一次。以后可用 `/tcn about` 随时打开，查看介绍不会改变汉化开关。

## 使用前了解

**适用版本与界面。** 面向军团再临 7.3.5 的原版界面；第三方任务界面、世界气泡、聊天框台词和过场字幕暂未适配。

**仍有内容会显示原文。** 当前资源收录了 21,376 个至少有部分中文内容的任务、8,412 条交任务对话、6,112 条任务进行中对话，以及 1,705 页可匹配的书籍和信件。这些数字包含旧资料片内容，不代表每个任务都已完整翻译，也不是 Tauri 服务器的实测覆盖率。服务器文字有改动、匹配不确定或缺少译文时，会继续显示原文。

**译文来源。** 优先采用有客户端采集记录的中文资料，并使用社区保存的中文数据库补充。部分内容尚未核实为官方原文；插件不使用机器翻译，也不自动把繁体转成简体。详细来源与署名见 [SOURCES.md](SOURCES.md)。

**近期修复。** 1.1.4 修正了连续角色称呼和换行显示、中文客户端的职业与种族匹配、已完成任务目标漏翻，以及任务标题状态丢失和长标题行高问题。这些修复已通过自动测试，实际游戏中的显示、滚动和兼容性仍需继续验证。

## 遇到问题怎么办？

如果插件没有生效，先检查安装路径和角色选择界面的插件勾选状态，再输入 `/tcn on` 并重新打开相关窗口。更新后仍有异常时，可以暂时停用其他修改任务或对话窗口的插件，确认是否存在冲突。

如果只有某一段没有翻译，可能是尚未收录或没有匹配到。欢迎到 **[GitHub Issues](https://github.com/zzz1999/TauriChinese/issues)** 反馈缺失译文、显示异常或改进建议。请尽量附上：

- 插件版本：可在 `/tcn about` 中查看。
- 客户端版本和使用的语言。
- 任务、NPC 或书籍名称；书籍问题请注明页码。
- 问题截图，以及出现问题时的操作。
- 如果同时使用其他任务或对话插件，请注明名称。

游戏内介绍窗口也提供反馈网址：点击网址，按 **Ctrl+C** 复制，再到浏览器中打开。
