# LegionChinese

为《魔兽世界》军团再临 **7.3.5** 客户端提供任务、NPC 对话、书籍、角色读条、宠物默认名称及场景物件提示的中文显示。

**版本：1.2.0** · 离线使用 · 无需翻译密钥 · 简体优先，繁体补充

**[下载最新版](https://github.com/zzz1999/LegionChinese/releases/latest/download/LegionChinese-latest.zip)** · [查看版本记录](https://github.com/zzz1999/LegionChinese/releases) · [反馈问题与建议](https://github.com/zzz1999/LegionChinese/issues)

插件不依赖某个服务器的专用接口，使用原版 7.3.5 界面和离线中文资料。保留这些接口、且文字能与资料库匹配的其他 7.3.5 客户端也可以使用；不同服务器的自定义内容、改动过的文字或界面仍可能需要单独适配，不能保证所有 7.3.5 客户端都完整汉化。

## 可以翻译哪些内容？

- **任务**：原版任务窗口、任务日志中的标题、正文、目标，以及进行中和交任务时的对话；右侧任务追踪栏的任务标题、目标和交付提示。
- **NPC 对话**：原版对话窗口中的文字和选项。
- **书籍与信件**：原版阅读窗口中的书页正文。
- **角色读条**：施法、引导、采集及使用物品的原版进度条。内置 7.3.5 中文法术名称，客户端只返回英文时也能匹配；支持原版受控宠物读条。
- **自己的宠物与召唤物**：有可靠对应的默认名称，如小鬼、虚空行者、食尸鬼及猎人宠物的默认种类名。覆盖原版宠物、目标、焦点头像框、鼠标提示和插件可访问的原版姓名板。
- **场景物件（GameObject）**：鼠标指向传送门、宝箱、矿点、路牌等物件时，匹配原版提示框中的英文名称。例如 `Death Gate` 显示为“死亡之门”。当前有 6,305 组名称匹配，其中 1,230 组使用繁体补充；这不是物件总数或实测覆盖率。未知或同名译文冲突时保留原文；不改变点击和交互行为。

已有简体或繁体中文保持原样；需要翻译的内容优先显示简体中文，没有可用简体时使用繁体，两者都没有时保留原文。标题和正文分别处理，因此中文标题下的英文正文也可以翻译。

译文随插件一起安装，无需联网翻译或申请 API 密钥。中文客户端沿用魔兽世界原有字体，与周围界面保持一致。其他语言客户端优先使用游戏自带中文字体，缺少该字体时才使用安装包中的后备字体。

读条名称来自 **7.3.5.26972 客户端数据的存档**，已随安装包提供，无需另外下载。当前包含 **160,721 个法术 ID** 的中文名称，其中 19,546 个使用繁体补充；包含 NPC 技能、历史技能等，不等于玩家可施放技能的数量。优先按法术 ID 匹配，没有 ID 时只采用对应关系明确的名称；找不到时继续尝试客户端自带中文，再保留原文。

**随机宠物名保持原样**，例如 `Casketmasher` 不会被改成“食尸鬼”或自行音译。猎人宠物只有在仍可改名、且名字与默认种类一致时才翻译；其他自定义名字保持原样。插件只改变界面显示，不给宠物改名。未开启姓名板时，由游戏引擎直接绘制的头顶浮动名字暂不能替换。

## 先把客户端语言设为简体中文

如果客户端已有中文界面，可以跳过本节。其他情况下，先确认安装中包含 **7.3.5 对应的简体中文语言资源**，再按以下步骤设置：

1. 完全退出游戏及登录器，备份游戏目录下的 `WTF\Config.wtf`。
2. 用记事本打开该文件，找到 `textLocale` 和 `audioLocale` 两项，分别改为下面的内容。没有对应行时添加；已有的行直接修改，不要重复添加。

   ```text
   SET textLocale "zhCN"
   SET audioLocale "zhCN"
   ```

3. 保存后，使用该 7.3.5 客户端原本配套的登录器启动游戏。只修改上述语言项，保留服务器连接等其他设置。

`textLocale` 控制文字语言，`audioLocale` 控制语音语言。如果只需要中文文字，语音项可以保留原来可用的语言。**修改配置不会补齐缺少的语言资源**；缺少中文文件时，需要通过该 7.3.5 客户端配套的下载或修复功能补齐。若改后无法启动，恢复备份再检查客户端语言资源及登录器设置。

客户端语言设置负责游戏已有的中文界面和资源，LegionChinese 则补充仍显示外文的任务、对话、书籍和读条等内容。即使配置为 `zhCN`，服务器没有提供中文的内容也不一定会自动变成中文。

## 安装与更新

1. **退出游戏**，下载上方的 `LegionChinese-latest.zip` 安装包。
2. 解压，将里面的 `LegionChinese` 文件夹放入游戏目录的 `Interface\AddOns\`。
3. 确认文件路径如下，避免多套一层文件夹：

   ```text
   魔兽世界游戏目录
   └─ Interface
      └─ AddOns
         └─ LegionChinese
            └─ LegionChinese.toc
   ```

4. 重新启动游戏，在角色选择界面的“插件”列表中勾选 **LegionChinese**。请停用 TauriHun 等同类文本替换插件，避免互相覆盖。
5. 进入游戏即可使用，**首次安装默认开启汉化**。

更新时退出游戏，用新安装包中的 `LegionChinese` 文件夹替换旧文件夹，再重新启动游戏。插件会保留之前的开关设置；如果以前手动关闭过，输入 `/lcn on` 即可重新开启。无需删除 `WTF` 文件夹。

请下载上面的插件安装包；GitHub 自动提供的 `Source code` 压缩包是项目源码，不能直接作为插件目录安装。

## 常用命令

在游戏聊天框中输入：

| 命令 | 用途 |
|---|---|
| `/lcn` | 查看当前汉化状态和命令提示 |
| `/lcn on` | 开启汉化 |
| `/lcn off` | 关闭汉化 |
| `/lcn about` | 查看插件版本、作者和反馈地址 |

切换开关后，关闭并重新打开当前任务、对话或书籍窗口；右侧任务追踪栏、当前读条、已显示的宠物名称和场景物件提示会自动刷新。也可以重新施法或将鼠标移到宠物、场景物件上检查效果。

首次进入游戏时会弹出介绍窗口，同一游戏账号只自动显示一次。以后可用 `/lcn about` 随时打开，查看介绍不会改变汉化开关。

## 使用前了解

**适用版本与界面。** 面向军团再临 7.3.5 的原版界面，数据与接口核对主要以 7.3.5.26972 为依据。其他 7.3.5 构建及服务器需要实际验证；第三方任务界面和读条、目标与焦点读条、世界气泡、聊天框台词和过场字幕暂未适配。本项目没有声明支持其他资料片版本。

**仍有内容会显示原文。** 当前资源收录了 21,376 个至少有部分中文内容的任务、8,411 条交任务对话、6,112 条任务进行中对话，以及 1,704 页可匹配的书籍和信件。这些数字包含旧资料片内容，不代表每个任务都已完整翻译，也不是任何服务器的实测覆盖率。服务器文字有改动、匹配不确定、动态内容无法解析或缺少译文时，会继续显示原文。

**译文来源。** 优先采用有客户端采集记录的中文资料，并使用社区保存的中文数据库补充。部分内容尚未核实为官方原文；插件不使用机器翻译，也不自动把繁体转成简体。详细来源与署名见 [SOURCES.md](SOURCES.md)。

**近期更新。** 1.2.0 新增场景物件名称汉化，补上截图中 `Death Gate` 的鼠标提示。物件名称与技能名称分别匹配，因此传送门可显示“死亡之门”，对应技能仍显示“黑锋之门”。项目名为 LegionChinese，游戏命令为 `/lcn`。自动测试不能代替实际游戏中的字形、布局和兼容性验证；新版本不代表所有内容已经翻译完成。

## 遇到问题怎么办？

如果插件没有生效，先检查安装路径和角色选择界面的插件勾选状态，再输入 `/lcn on` 并重新打开相关窗口。更新后仍有异常时，可以暂时停用其他修改任务或对话窗口的插件，确认是否存在冲突。

如果只有某一段没有翻译，可能是尚未收录或没有匹配到。欢迎到 **[GitHub Issues](https://github.com/zzz1999/LegionChinese/issues)** 反馈缺失译文、显示异常或改进建议。请尽量附上：

- 插件版本：可在 `/lcn about` 中查看。
- 客户端版本和使用的语言。
- 任务、NPC、书籍、施法动作或宠物名称；书籍问题请注明页码，宠物问题请注明职业和显示位置。
- 问题截图，以及出现问题时的操作。
- 如果同时使用其他任务或对话插件，请注明名称。

游戏内介绍窗口也提供反馈网址：点击网址，按 **Ctrl+C** 复制，再到浏览器中打开。
