# LegionChinese

<img src="assets/legion-chinese-icon-400.png" alt="LegionChinese：邪能连接的石质文字与右下角烧损的书本" width="160" height="160">

为《魔兽世界》军团再临 **7.3.5** 客户端提供任务、NPC 对话、书籍、神器界面、角色读条、宠物默认名称及场景物件提示的中文显示。

**版本：1.3.1** · 离线使用 · 无需翻译密钥 · 简体优先，繁体补充

**[下载最新版](https://github.com/zzz1999/LegionChinese/releases/latest)** · [查看版本记录](https://github.com/zzz1999/LegionChinese/releases) · [反馈问题与建议](https://github.com/zzz1999/LegionChinese/issues)

插件不依赖某个服务器的专用接口，使用原版 7.3.5 界面和离线中文资料。保留这些接口、且文字能与资料库匹配的其他 7.3.5 客户端也可以使用；不同服务器的自定义内容、改动过的文字或界面仍可能需要单独适配，不能保证所有 7.3.5 客户端都完整汉化。

## 可以翻译哪些内容？

- **任务**：原版任务窗口、任务日志中的标题、正文、目标，以及进行中和交任务时的对话；任务肖像旁的人物名称与介绍、右侧任务追踪栏的任务标题、目标和交付地点提示。
- **地图与世界任务**：世界地图可接任务图标的提示标题会查询已有中文库，例如“A Recent Discovery”显示为“近期发现”；已接任务和世界任务提示中的标题、目标也会查询中文。右侧世界任务、奖励目标及场景目标保留实际进度和计时。同名译文有冲突或没有对应时保留原文。大酋长征令板现已补充艾萨拉、北贫瘠之地、银松森林三个地区名，卡片说明和按钮尚未找到可靠译文时保持原样。卫兵指路的小地图标签“Orgrimmar Portals”目前也保留原文。
- **NPC 对话与头衔**：原版对话窗口中的文字和选项，以及鼠标提示中的 NPC 名称与头衔。确认窗口有可匹配译文时也会替换文字。普通 NPC 的原版头像框、可访问姓名板按 NPC ID 和完整名称匹配，玩家和自定义名称不变。
- **书籍与信件**：原版阅读窗口中的书页正文。部分重复正文需要从第一页开始阅读，才能根据书籍和页码选取对应译文。
- **角色读条**：施法、引导、采集及使用物品的原版进度条。内置 7.3.5 中文法术名称，客户端只返回英文时也能匹配；支持原版受控宠物、目标和焦点读条。
- **自己的宠物与召唤物**：有可靠对应的默认名称，如小鬼、虚空行者、食尸鬼及猎人宠物的默认种类名。覆盖原版宠物、目标、焦点头像框、鼠标提示和插件可访问的原版姓名板。
- **场景物件（GameObject）**：鼠标指向传送门、宝箱、矿点、路牌等物件时，匹配原版提示框中的英文名称。例如 `Death Gate` 显示为“死亡之门”，`Portal to Ashran` 显示为“到阿什兰的传送门”。当前有 6,306 组名称匹配，其中 1,230 组使用繁体补充；这不是物件总数或实测覆盖率。未知或同名译文冲突时保留原文；不改变点击和交互行为。
- **物品说明**：补充物品提示底部仍显示英文的背景、用途等固定说明，通常是黄色文字。内置 7.3.5 客户端中文说明，覆盖 16,326 个物品 ID（16,302 简体、24 繁体，含原有钥石说明），支持背包悬停、点击聊天物品链接和原版装备对比提示。按物品 ID 和原文共同匹配，已有中文保持原样。装备属性、实际数值、钥石层数与词缀由游戏显示；带动态数值公式的物品说明及未匹配内容暂保留原文。这不是所有物品效果的完整汉化库。
- **聊天中的链接名称**：按可点击链接的类型和 ID，尝试汉化物品、钥石、任务、法术、制作配方、成就、货币、天赋、战斗宠物及其技能名称。支持原版不带方括号的战斗宠物技能链接，保留原有显示格式。物品、任务、法术、成就、货币、战斗宠物及技能还会查询插件的离线中文库。其中物品名称覆盖 103,910 个 ID；无法确认的随机后缀或奖励变体名称会等待客户端的准确中文名称，不用基础名替代。手打的普通 `[文字]`、玩家姓名和没有可靠中文的链接保持原样。首次遇到未缓存的物品时，中文资料加载后会自动更新已经显示的那条消息；点开物品详情时也会重新检查。钥石会显示为“钥石：英灵殿 (12)”这样的中文副本名与层数。适用于频道、队伍、团队、公会、密语和拾取消息等原版聊天窗口，保留链接颜色、物品属性、钥石词缀和聊天正文，点击仍打开原链接指向的内容。已有中文不变。
- **NPC 聊天与动作提示**：匹配聊天中的 NPC 说话、喊话、密语，以及怪物和首领动作提示，例如“钢鬃掠夺者充满恐惧地想要转身逃跑！”。原版头像对白、可访问的 NPC 头顶气泡，以及由 NPC 说话事件生成的过场字幕也会查询已有对白库。玩家发言正文保持原样；受保护气泡、视频内嵌字幕和未收录内容保留原样。
- **聊天中的副本链接**：冒险指南和副本进度链接会按 ID 显示中文副本名，例如“英灵殿”“暗夜要塞”。内置 7.3.5 的简繁中文副本、首领和技能名称，保留难度、进度和点击功能。玩家手打的 `Halls of Valor`、`HOV` 等普通文字保持原样。
- **法术与光环提示**：补充原版提示框中的静态法术说明、增益／减益说明和技能副标题，按法术 ID 与原文匹配。另有部分数值说明可以在完整文字结构匹配时保留当前提示中的数值并替换说明；不自行计算伤害、治疗或持续时间。复杂公式、未知格式和服务器改过的正文仍保留原文。
- **成就、货币与战斗宠物说明**：原版成就页面的说明和奖励、成就与货币提示框、宠物手册的背景和来源、宠物技能提示会查询同版中文资料。宠物技能沿用游戏当前属性计算；玩家自定义宠物名保持原样。
- **冒险指南与推荐**：补充首领介绍、可匹配的章节说明，以及冒险推荐卡片的标题、说明和按钮。带未解析公式的章节、缺少对应的文字仍保留原文，不改变副本难度、奖励或点击对象。
- **神器**：补充原版神器窗口中的武器名称、外观组名称、外观解锁要求及可用特质通知。神器与虚空熔炉的特质提示会查询现有中文法术名称和说明，实际等级与数值取自客户端。神器选择界面已收录法师三系、德鲁伊平衡／野性／守护的 6 段介绍，以及部分专精标签和选择按钮；其他未核实对白继续保留原文。
- **客户端固定文字补充**：任务与场景目标、成就条件、地图地点和区域标签，以及原版坐骑手册、地下城排队说明、专业配方来源、声望详情、要塞任务介绍中的固定文字，会查询新补充的同版中文资料。按完整原文匹配，保留实际进度、奖励、计时和自定义名称；收录资料不代表每个界面入口已经全部适配。

已有简体或繁体中文保持原样；需要翻译的内容优先显示简体中文，没有可用简体时使用繁体，两者都没有时保留原文。标题和正文分别处理，因此中文标题下的英文正文也可以翻译。

译文随插件一起安装，无需联网翻译或申请 API 密钥。中文客户端沿用魔兽世界原有字体，与周围界面保持一致。`/lcn about` 也使用游戏字体。安装包不再附带第三方字体；其他语言客户端需要已有的魔兽世界中文字体资源。

读条名称来自 **7.3.5.26972 客户端数据的存档**，已随安装包提供，无需另外下载。当前包含 **160,721 个法术 ID** 的中文名称，其中 19,546 个使用繁体补充；包含 NPC 技能、历史技能等，不等于玩家可施放技能的数量。优先按法术 ID 匹配，没有 ID 时只采用对应关系明确的名称；找不到时继续尝试客户端自带中文，再保留原文。

**随机宠物名也会查找中文对应，找到可靠译文后随版本补充**。食尸鬼和术士召唤物的随机姓名均纳入查找范围，优先采用官方译文，按“简体 → 繁体 → 原名”回退。截至 2026-10-17，尚未收录能核对到随机姓名本身的中文对应，`Casketmasher` 等暂时保留原名；插件离线使用，不会在游戏中联网搜索或自动生成译名。

猎人宠物只有在仍可改名、且名字与默认种类一致时才翻译；玩家起的其他自定义名字保持原样。插件只改变界面显示，不给宠物改名。未开启姓名板时，由游戏引擎直接绘制的头顶浮动名字暂不能替换。

从旧版更新时，退出游戏后先删除旧的 `Interface/AddOns/LegionChinese` 文件夹，再解压新版本，避免旧字体或资源分片残留；不需要删除 `WTF` 中的插件设置。

## 先把客户端语言设为简体中文

如果客户端已有中文界面，可以跳过本节。其他情况下，先确认安装中包含 **7.3.5 对应的简体中文语言资源**，再按以下步骤设置：

1. 完全退出游戏及登录器，备份游戏目录下的 `WTF\Config.wtf`。
2. 用记事本打开该文件，找到 `textLocale` 和 `audioLocale` 两项，分别改为下面的内容。没有对应行时添加；已有的行直接修改，不要重复添加。

   ```text
   SET textLocale "zhCN"
   SET audioLocale "zhCN"
   ```

3. 保存后，使用该 7.3.5 客户端原本配套的登录器启动游戏。只修改上述语言项，保留服务器连接等其他设置。

`textLocale` 控制文字语言，`audioLocale` 控制语音语言。如果只需要中文文字，语音项可以保留原来可用的语言。**修改配置不会补齐缺少的语言资源**；缺少中文文件时，需要通过该 7.3.5 客户端配套的下载或修复功能补齐。若改后无法启动，恢复备份再检查客户端语言资源及登录器设置。

客户端语言设置负责游戏已有的中文界面和资源，LegionChinese 则补充仍显示外文的任务、对话、书籍和读条等内容。即使配置为 `zhCN`，服务器没有提供中文的内容也不一定会自动变成中文。

## 安装与更新

1. **退出游戏**，打开上方“下载最新版”，在 **Assets** 中下载 `LegionChinese-版本号.zip` 安装包，例如 `LegionChinese-1.3.1.zip`。
2. 解压，将里面的 `LegionChinese` 文件夹放入游戏目录的 `Interface\AddOns\`。
3. 确认文件路径如下，避免多套一层文件夹：

   ```text
   魔兽世界游戏目录
   └─ Interface
      └─ AddOns
         └─ LegionChinese
            └─ LegionChinese.toc
   ```

4. 重新启动游戏，在角色选择界面的“插件”列表中勾选 **LegionChinese**。请停用 TauriHun 等同类文本替换插件，避免互相覆盖。
5. 进入游戏即可使用，**插件加载后自动汉化，无需额外开启**。

更新时退出游戏，用新安装包中的 `LegionChinese` 文件夹替换旧文件夹，再重新启动游戏。插件加载后就会自动汉化，旧版保存的关闭状态不再生效。介绍窗口的已读记录会保留，无需删除 `WTF` 文件夹。

请下载上面的插件安装包；GitHub 自动提供的 `Source code` 压缩包是项目源码，不能直接作为插件目录安装。

## 常用命令

在游戏聊天框中输入：

| 命令 | 用途 |
|---|---|
| `/lcn` | 查看命令提示 |
| `/lcn about` | 查看插件版本、本版更新记录、作者和反馈地址 |

无需设置汉化开关。如需停用，在角色选择界面的“插件”列表中取消勾选 LegionChinese，再进入游戏。

首次进入游戏时会弹出介绍窗口，同一游戏账号只自动显示一次。以后可用 `/lcn about` 随时打开，用鼠标滚轮或右侧滚动条阅读本版更新记录及下载、反馈地址。关闭介绍窗口不影响汉化。

## 使用前了解

**适用版本与界面。** 面向军团再临 7.3.5 的原版界面，数据与接口核对主要以 7.3.5.26972 为依据。其他 7.3.5 构建及服务器需要实际验证；第三方任务界面和读条、受保护气泡、视频内嵌字幕暂未适配。支持一种显示入口不代表其中全部文字都有可靠中文。本项目没有声明支持其他资料片版本。

**仍有内容会显示原文。** 基础任务库收录 22,703 个至少有部分中文内容的任务，另有按完整原文匹配的任务字段和对白补充库，任务 ID 之间存在重叠，不能直接相加。书籍有 1,704 页可直接匹配，另外 51 页需要根据第一页和页码识别。这些数字包含旧资料片内容，不代表每个任务都已完整翻译，也不是任何服务器的实测覆盖率。服务器文字有改动、匹配不确定、动态内容无法解析或缺少译文时，会继续显示原文。

**译文来源。** 优先采用有客户端采集记录的中文资料，并使用社区保存的中文数据库补充。部分内容尚未核实为官方原文；插件不使用机器翻译，也不自动把繁体转成简体。详细来源与署名见 [SOURCES.md](SOURCES.md)。

**聊天链接需要可靠的名称资料。** 聊天里原本显示的是发送者附带的名称，点开详情则由本机客户端读取，因此两处语言可能不同。插件会在本机中文资料可用后更新聊天栏中的链接名称，包括仍保留在原版聊天记录中的消息，不需要让对方重新发送。没有可用中文名称时仍保留原文；不会翻译玩家发言正文或向服务器发送消息。钥石需要链接中包含可识别的副本和层数，只有通用“史诗钥石”物品信息时不会猜测副本。第三方聊天插件若替换了原版聊天记录结构，可能只能处理收到时已缓存的物品。

**近期更新。** 1.3.1 整理功能模块和资源目录，合并有收益的重复中文资源，改进界面迟加载处理，并增加构建回滚与加载顺序校验。汉化资料与 1.3.0 保持一致，简体、繁体回退规则不变。完整记录见 [CHANGELOG.md](CHANGELOG.md)，覆盖范围见 [汉化资料范围](docs/TRANSLATION-COVERAGE.md)。仍需实际游戏核验布局与兼容性。

## 遇到问题怎么办？

如果插件没有生效，先检查安装路径和角色选择界面的插件勾选状态，再重新进入游戏并打开相关窗口。更新后仍有异常时，可以暂时停用其他修改任务或对话窗口的插件，确认是否存在冲突。

如果只有某一段没有翻译，可能是尚未收录或没有匹配到。请在 **[提交反馈](https://github.com/zzz1999/LegionChinese/issues/new/choose)** 中选择“汉化缺失或使用问题”，按照表单填写；新功能可选择“功能建议”。请尽量附上：

- 插件版本：可在 `/lcn about` 中查看。
- 客户端版本和使用的语言。
- 任务、NPC、书籍、物品、施法动作或宠物名称；书籍问题请注明页码，物品问题请附完整提示框，宠物问题请注明职业和显示位置。
- 问题截图，以及出现问题时的操作。
- 如果同时使用其他任务或对话插件，请注明名称。

游戏内介绍窗口也提供反馈网址：点击网址，按 **Ctrl+C** 复制，再到浏览器中打开。
