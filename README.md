# LegionChinese

<img src="assets/legion-chinese-icon-400.png" alt="LegionChinese：邪能连接的石质文字与右下角烧损的书本" width="160" height="160">

为《魔兽世界》军团再临 **7.3.5** 客户端提供任务、NPC 对话、书籍、角色读条、宠物默认名称及场景物件提示的中文显示。

**版本：1.2.10** · 离线使用 · 无需翻译密钥 · 简体优先，繁体补充

**[下载最新版](https://github.com/zzz1999/LegionChinese/releases/latest)** · [查看版本记录](https://github.com/zzz1999/LegionChinese/releases) · [反馈问题与建议](https://github.com/zzz1999/LegionChinese/issues)

插件不依赖某个服务器的专用接口，使用原版 7.3.5 界面和离线中文资料。保留这些接口、且文字能与资料库匹配的其他 7.3.5 客户端也可以使用；不同服务器的自定义内容、改动过的文字或界面仍可能需要单独适配，不能保证所有 7.3.5 客户端都完整汉化。

## 可以翻译哪些内容？

- **任务**：原版任务窗口、任务日志中的标题、正文、目标，以及进行中和交任务时的对话；右侧任务追踪栏的任务标题、目标和交付提示。
- **NPC 对话**：原版对话窗口中的文字和选项。
- **书籍与信件**：原版阅读窗口中的书页正文。
- **角色读条**：施法、引导、采集及使用物品的原版进度条。内置 7.3.5 中文法术名称，客户端只返回英文时也能匹配；支持原版受控宠物读条。
- **自己的宠物与召唤物**：有可靠对应的默认名称，如小鬼、虚空行者、食尸鬼及猎人宠物的默认种类名。覆盖原版宠物、目标、焦点头像框、鼠标提示和插件可访问的原版姓名板。
- **场景物件（GameObject）**：鼠标指向传送门、宝箱、矿点、路牌等物件时，匹配原版提示框中的英文名称。例如 `Death Gate` 显示为“死亡之门”，`Portal to Ashran` 显示为“到阿什兰的传送门”。当前有 6,306 组名称匹配，其中 1,230 组使用繁体补充；这不是物件总数或实测覆盖率。未知或同名译文冲突时保留原文；不改变点击和交互行为。
- **钥石使用说明**：补充军团再临史诗钥石提示底部的使用说明，支持背包悬停和点击聊天中的钥石链接。目前这条说明使用已找到的繁体译文；层数、词缀和剩余时间保持原样。这不是完整的物品说明汉化库。
- **聊天中的链接名称**：识别方括号背后的链接类型和 ID，尝试汉化物品、钥石、任务、法术、制作配方、成就、货币、天赋、战斗宠物及其技能名称。任务和法术还会查询插件的离线中文库。手打的普通 `[文字]`、玩家姓名和没有可靠中文的链接保持原样。首次遇到未缓存的物品时，中文资料加载后会自动更新已经显示的那条消息；点开物品详情时也会重新检查。钥石会显示为“钥石：英灵殿 (12)”这样的中文副本名与层数。适用于频道、队伍、团队、公会、密语和拾取消息等原版聊天窗口，保留链接颜色、物品属性、钥石词缀和聊天正文，点击仍打开原链接指向的内容。已有中文不变。
- **怪物动作提示**：匹配聊天中的怪物和首领动作提示，例如“钢鬃掠夺者充满恐惧地想要转身逃跑！”。仅处理系统的怪物动作事件，不翻译玩家发言。
- **聊天中的副本链接**：冒险指南和副本进度链接会按 ID 显示中文副本名，例如“英灵殿”“暗夜要塞”。内置 7.3.5 的简繁中文名称，保留难度、进度和点击功能。冒险指南的首领、技能链接在客户端有中文资料时也会尝试汉化。玩家手打的 `Halls of Valor`、`HOV` 等普通文字保持原样。

已有简体或繁体中文保持原样；需要翻译的内容优先显示简体中文，没有可用简体时使用繁体，两者都没有时保留原文。标题和正文分别处理，因此中文标题下的英文正文也可以翻译。

译文随插件一起安装，无需联网翻译或申请 API 密钥。中文客户端沿用魔兽世界原有字体，与周围界面保持一致。`/lcn about` 也使用游戏字体。安装包不再附带第三方字体；其他语言客户端需要已有的魔兽世界中文字体资源。

读条名称来自 **7.3.5.26972 客户端数据的存档**，已随安装包提供，无需另外下载。当前包含 **160,721 个法术 ID** 的中文名称，其中 19,546 个使用繁体补充；包含 NPC 技能、历史技能等，不等于玩家可施放技能的数量。优先按法术 ID 匹配，没有 ID 时只采用对应关系明确的名称；找不到时继续尝试客户端自带中文，再保留原文。

**随机宠物名也会查找中文对应，找到可靠译文后随版本补充**。食尸鬼和术士召唤物的随机姓名均纳入查找范围，优先采用官方译文，按“简体 → 繁体 → 原名”回退。截至 2026-10-17，尚未收录能核对到随机姓名本身的中文对应，`Casketmasher` 等暂时保留原名；插件离线使用，不会在游戏中联网搜索或自动生成译名。

猎人宠物只有在仍可改名、且名字与默认种类一致时才翻译；玩家起的其他自定义名字保持原样。插件只改变界面显示，不给宠物改名。未开启姓名板时，由游戏引擎直接绘制的头顶浮动名字暂不能替换。

从旧版更新时，退出游戏后先删除旧的 `Interface/AddOns/LegionChinese` 文件夹，再解压新版本，避免旧字体或资源分片残留；不需要删除 `WTF` 中的插件设置。

## 先把客户端语言设为简体中文

如果客户端已有中文界面，可以跳过本节。其他情况下，先确认安装中包含 **7.3.5 对应的简体中文语言资源**，再按以下步骤设置：

1. 完全退出游戏及登录器，备份游戏目录下的 `WTF\Config.wtf`。
2. 用记事本打开该文件，找到 `textLocale` 和 `audioLocale` 两项，分别改为下面的内容。没有对应行时添加；已有的行直接修改，不要重复添加。

   ```text
   SET textLocale "zhCN"
   SET audioLocale "zhCN"
   ```

3. 保存后，使用该 7.3.5 客户端原本配套的登录器启动游戏。只修改上述语言项，保留服务器连接等其他设置。

`textLocale` 控制文字语言，`audioLocale` 控制语音语言。如果只需要中文文字，语音项可以保留原来可用的语言。**修改配置不会补齐缺少的语言资源**；缺少中文文件时，需要通过该 7.3.5 客户端配套的下载或修复功能补齐。若改后无法启动，恢复备份再检查客户端语言资源及登录器设置。

客户端语言设置负责游戏已有的中文界面和资源，LegionChinese 则补充仍显示外文的任务、对话、书籍和读条等内容。即使配置为 `zhCN`，服务器没有提供中文的内容也不一定会自动变成中文。

## 安装与更新

1. **退出游戏**，打开上方“下载最新版”，在 **Assets** 中下载 `LegionChinese-版本号.zip` 安装包，例如 `LegionChinese-1.2.10.zip`。
2. 解压，将里面的 `LegionChinese` 文件夹放入游戏目录的 `Interface\AddOns\`。
3. 确认文件路径如下，避免多套一层文件夹：

   ```text
   魔兽世界游戏目录
   └─ Interface
      └─ AddOns
         └─ LegionChinese
            └─ LegionChinese.toc
   ```

4. 重新启动游戏，在角色选择界面的“插件”列表中勾选 **LegionChinese**。请停用 TauriHun 等同类文本替换插件，避免互相覆盖。
5. 进入游戏即可使用，**首次安装默认开启汉化**。

更新时退出游戏，用新安装包中的 `LegionChinese` 文件夹替换旧文件夹，再重新启动游戏。插件会保留之前的开关设置；如果以前手动关闭过，输入 `/lcn on` 即可重新开启。无需删除 `WTF` 文件夹。

请下载上面的插件安装包；GitHub 自动提供的 `Source code` 压缩包是项目源码，不能直接作为插件目录安装。

## 常用命令

在游戏聊天框中输入：

| 命令 | 用途 |
|---|---|
| `/lcn` | 查看当前汉化状态和命令提示 |
| `/lcn on` | 开启汉化 |
| `/lcn off` | 关闭汉化 |
| `/lcn about` | 查看插件版本、作者和反馈地址 |

切换开关后，关闭并重新打开当前任务、对话或书籍窗口；右侧任务追踪栏、当前读条、已显示的宠物名称、场景物件提示、钥石说明和原版聊天栏中的物品链接会自动刷新。`/lcn on` 也会重新处理当前聊天记录；`/lcn off` 会还原本次运行中由插件替换的聊天链接名称。也可以重新施法或将鼠标移到宠物、场景物件上检查效果。

首次进入游戏时会弹出介绍窗口，同一游戏账号只自动显示一次。以后可用 `/lcn about` 随时打开，查看介绍不会改变汉化开关。

## 使用前了解

**适用版本与界面。** 面向军团再临 7.3.5 的原版界面，数据与接口核对主要以 7.3.5.26972 为依据。其他 7.3.5 构建及服务器需要实际验证；第三方任务界面和读条、目标与焦点读条、世界气泡、怪物普通说话和喊话、过场字幕暂未适配。本项目没有声明支持其他资料片版本。

**仍有内容会显示原文。** 当前资源收录了 22,700 个至少有部分中文内容的任务、8,730 条交任务对话、6,240 条任务进行中对话，以及 1,704 页可匹配的书籍和信件。这些数字包含旧资料片内容，不代表每个任务都已完整翻译，也不是任何服务器的实测覆盖率。服务器文字有改动、匹配不确定、动态内容无法解析或缺少译文时，会继续显示原文。

**译文来源。** 优先采用有客户端采集记录的中文资料，并使用社区保存的中文数据库补充。部分内容尚未核实为官方原文；插件不使用机器翻译，也不自动把繁体转成简体。详细来源与署名见 [SOURCES.md](SOURCES.md)。

**聊天链接需要可靠的名称资料。** 聊天里原本显示的是发送者附带的名称，点开详情则由本机客户端读取，因此两处语言可能不同。插件会在本机中文资料可用后更新聊天栏中的链接名称，包括仍保留在原版聊天记录中的消息，不需要让对方重新发送。没有可用中文名称时仍保留原文；不会翻译聊天正文或向服务器发送消息。钥石需要链接中包含可识别的副本和层数，只有通用“史诗钥石”物品信息时不会猜测副本。第三方聊天插件若替换了原版聊天记录结构，可能只能处理收到时已缓存的物品。

**近期更新。** 1.2.10 补齐聊天中可点击的副本名称，加入同版本客户端中文副本名称库。1.2.9 修复任务链接在聊天中仍显示英文的问题，扩展多种链接名称汉化和怪物动作提示；从同版本任务资料库补入 13,727 个缺失字段，保留已有译文；移除随包字体。1.2.4 修复“点开物品详情是中文，聊天栏仍保留外文名称”的缓存更新缺口，并覆盖拾取消息、已有聊天记录和临时密语窗口；加入史诗钥石聊天名称汉化，保留副本和层数，并修正原生钥石链接的使用说明识别。包含 1.2.2 的阿什兰传送门、钥石使用说明，以及 1.2.1 的布林顿每日礼物正文修复。反馈中的 `HERETICS WILL BURN` 告示尚未找到可靠的简繁中文记录，继续保留原文。自动测试不能代替实际游戏中的字形、布局和兼容性验证；新版本不代表所有内容已经翻译完成。

## 遇到问题怎么办？

如果插件没有生效，先检查安装路径和角色选择界面的插件勾选状态，再输入 `/lcn on` 并重新打开相关窗口。更新后仍有异常时，可以暂时停用其他修改任务或对话窗口的插件，确认是否存在冲突。

如果只有某一段没有翻译，可能是尚未收录或没有匹配到。欢迎到 **[GitHub Issues](https://github.com/zzz1999/LegionChinese/issues)** 反馈缺失译文、显示异常或改进建议。请尽量附上：

- 插件版本：可在 `/lcn about` 中查看。
- 客户端版本和使用的语言。
- 任务、NPC、书籍、施法动作或宠物名称；书籍问题请注明页码，宠物问题请注明职业和显示位置。
- 问题截图，以及出现问题时的操作。
- 如果同时使用其他任务或对话插件，请注明名称。

游戏内介绍窗口也提供反馈网址：点击网址，按 **Ctrl+C** 复制，再到浏览器中打开。
