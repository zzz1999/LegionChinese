# 1.2.16 显示入口与说明补充

本次处理此前审查中有可靠对应、但缺少界面入口或导入流程的内容。没有中文对应的条目不生成新译文，保持“简体 → 繁体 → 原文”。资源统计见 [汉化资料范围](TRANSLATION-COVERAGE.md)，实际游戏中的命中率与排版仍需验收。

## 数据来源与配对

`ClientTexts` 读取 `sources.json.extraLinkTables` 和 `questBoardTables` 中固定 SHA-256 的 7.3.5.26972 三语 CSV。包括 Achievement、CurrencyTypes、BattlePetSpecies、BattlePetAbility、JournalEncounter、JournalEncounterSection 和 AdventureJournal。分别处理每个字段，不因某字段有简体就丢弃其他字段的繁体补缺。

每个字段保存 ID、完整原文指纹与中文。冒险推荐和部分货币／指南入口没有稳定 ID 时，仅使用该类别、该字段内没有译文冲突的完整原文索引。不同 ID 对同一原文给出不同译文时，保留按 ID 匹配，取消无 ID 匹配。未知标签、格式占位符和控制字符不直接进入静态说明。

`DynamicSpellTexts` 复用固定的同版 Spell 三语 CSV，仅接入能够明确对应的效果数值变量。原文结构完全一致、固定数字不变、重复变量数值一致时，从客户端当前提示中取数填入已有中文。复杂公式、持续时间、性别／条件分支、未知标记和格式变化不猜测。没有从基础数据库计算伤害、治疗或装备缩放。

战斗宠物技能中的方括号表达式是例外：原文和中文中的完整表达式集合必须完全一致，再交给原版 `SharedPetAbilityTooltip_ParseText`，使用当前宠物属性。先核对当前显示内容确实是原文的解析结果，中文解析失败时继续显示原文。不会执行新写的表达式。

## 原版显示入口

| 入口 | 处理方式与限制 |
| --- | --- |
| 世界地图可接、已接任务与世界任务 | 校验图标或原版任务上下文；多任务提示只改当前任务段，忽略奖励、阵营和剩余时间 |
| 世界任务、奖励目标和场景目标追踪 | 挂钩各模块的 `AddObjective`，保持计数和原版布局；场景阶段标题没有新增专用数据 |
| 目标／焦点读条 | 扩展原有施法匹配到原版指定读条；施法实例、法术 ID 和当前文字必须一致 |
| 装备对比提示 | 复用物品 ID 与完整说明校验；提示框换物品后重新匹配 |
| 普通 NPC 名称 | Creature GUID 与完整名称双重匹配；不处理玩家、玩家控制单位、宠物自定义名或其他插件的自定义标签 |
| 成就页面与货币提示 | 用 ID 与字段校验；成就文字在原版测量前替换 |
| 宠物手册与技能 | 物种、技能 ID 和当前文本校验，保留自定义宠物名称；动态表达式沿用游戏解析器 |
| 冒险指南与推荐 | 首领、章节、角色概览和推荐卡片；概览先等待原版更新条目 ID，防止复用框体串译 |
| 原版头像对白 | 对完整对白及 NPC 名称查询既有数据库；无匹配不改 |
| NPC 气泡 | 只在近期 NPC 说话／喊话有已知译文时扫描可访问气泡，原文须完整一致；同文玩家发言使匹配失效 |
| 事件字幕 | 只处理原版 CinematicFrame 的 NPC 说话／喊话字幕，保留发送者；玩家字幕和视频画面不变 |

接口依据固定的 [7.3.5 原版界面快照](https://github.com/Gethe/wow-ui-source/tree/67ecbf5ce0e50cc7483c2295caecf410460f0994)。以方法或框体脚本挂钩保留原版返回值和交互流程；延迟加载时补装，避免重复挂钩。

## 性能与保护

地图、追踪栏、读条和说明页面由原版事件或填字过程触发，没有全界面逐帧查找。法术提示复用现有提示框状态缓存，文字与对象未变化时不重复解析。

气泡 API 没有逐气泡文字更新事件，因此只在命中 NPC 对白后启用 0.1 秒间隔检查；待匹配记录最长 15 秒、最多 64 条，每次最多检查 64 个气泡，遍历深度最多两层。过期或切换场景后停止。玩家消息记录超过 64 条时暂停 15 秒，避免清理证据后把玩家气泡误判为 NPC。受保护气泡直接跳过；没有活跃待匹配记录时不扫描。

本次未新增不可靠翻译来填充任务／书籍冲突、其他神器选择正文、征令板说明、`Orgrimmar Portals` 或随机宠物名。继续沿用已有审核规则和来源记录，不把现代客户端改过的句子当作旧版官方译文。

## 反馈模板

GitHub 的 `.github/ISSUE_TEMPLATE/report.yml` 收集实际插件版本、客户端 build／语言／服务器、内容与显示位置、实际与预期、复现步骤，截图和可靠来源可选。不会要求使用者必须知道 ID 或自行翻译。`suggestion.yml` 用于功能建议；`config.yml` 关闭空白 Issue 入口。

模板推送到默认分支后，GitHub 新建 Issue 页面才会显示这些表单。
