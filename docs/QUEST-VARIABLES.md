# 任务变量补充范围

## 本轮接入

从 2018 年 build 26365 社区采集候选中核对 58 条语言记录，合并为 36 个任务字段。本次启用 33 个字段：23 个 `Objectives` 和 10 个 `Description`，25 个简体、8 个繁体。保留并验证了这 33 个字段的全部 55 条简繁记录；发行资源只选一种译文。其余 3 个 `$ct` 字段暂缓。

来源、固定修订、SQL 哈希、完整中英文和逐字段来源保存在 `data/quest-variables-735.json`。已发布的 v1.3.4 原有资料保持优先。新增字段来自社区保存的客户端采集资料，不称为暴雪官方发布的数据库，不附加人工或机器译文。

可用 `node scripts/audit-quest-variables.mjs <采集SQL目录> <TDB目录>` 重新检查源文件哈希、同 ID 原文、中文字段、标题及版本；该命令只读，不下载、不执行 SQL。

## 变量处理

- `$1oa`、`$2oa` 等表示任务原始目标数组中对应项的需求数量。它们不是当前完成进度，也不保证与界面可见目标顺序一致。
- 任务 ID、字段、完整原文的固定片段全部匹配后，从客户端已解析的原文读取对应数字，再填入中文。不会使用历史 SQL 的固定数量，也不会调用 `GetQuestObjectiveInfo()` 猜测隐藏目标的位置。
- `$p` 必须与当前玩家名匹配；配套 `$r` 使用现有种族对应。换角色后的值重新读取，不缓存前一个角色的变量。
- 只有已审核快照支持这些变量。普通资源仍拒绝不支持的 `$` 标记。原文有改动、变量未知、数量格式异常、重复数量不一致或玩家信息缺失时，保留整段原文。
- 数量必须是 0 至 2147483647 的规范十进制整数；不猜测小数、千位分隔符或异常前导零。

## 暂缓的职业称谓

46141、46143、46147 的正文使用 `$ct`，该变量读取 `ChrClassTitle`，不能用普通职业名称代替。本地 7.3.5.26972 提取到了中文表（12 个职业，分别有男女字段），但 enUS 和 zhTW 数据块缺失，当前没有可靠英文称谓供完整原文匹配。提取回执保存在快照的 `classTitleProbe` 中，这三个字段不写入安装资源。

## 验证边界

离线回归覆盖全部候选字段、简繁选择、原文变更、错误任务／字段、零值、多目标与重复变量、服务器修改需求数量、玩家名／种族变化、未解析变量和源文件哈希。完整项目构建另验证 Lua 5.1 语法、资源加载次序与中文数据约束。

这些检查不等于游戏内实测。游戏验收可选择任务 48067（多数量目标）、50231（单数量目标）、32268（玩家名和种族正文）：对照开启插件前后的实际需求数量，确认打开任务日志／接任务窗口后的中文、行高和段落正常。任务是否可接取取决于角色和服务器进度。
