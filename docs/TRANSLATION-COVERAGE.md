## 仍缺可靠依据或不能安全展示的内容

- **45 个任务候选字段**没有通过上下文、目标顺序或变量解析检查；另有 **11 个字段**在采集时缺少可核对原文或 build。世界状态值、职业复数等未知标记不能通过删除占位符来处理，详见两个任务审计文件。
- **9 个任务的进行中对白**仍缺可安全配对的英文原文：27944、27949、27970、27978、28059、28130、28882、29351、29419。拥有中文候选不等于可以按任务 ID 强行覆盖当前内容。
- 有中文候选但被静态说明规则排除的记录还有 **45,185 条法术描述、23,060 条光环描述、16 条副标题**。原因包括动态公式、缺少英文对照、内嵌标记或不支持的格式；这些数量不能全部视为正常玩家技能的漏译。伤害、治疗、持续时间和装备缩放必须使用游戏实际值，当前没有通用公式求值器。
- 原先 **118 个书页 ID**的正文有译文冲突，本次通过页链恢复其中可明确区分的内容。其余冲突、打开时不是第一页、第一页无法识别、服务器改动页序等情况仍保留原文。旧版本中缺少同版本原文或内容已改变的页面也不会强行加入。
- **神器／PlayerChoice 选择界面**找到的中文资料主要标记为后续 build（例如 27602、27843），尚不足以证明适用于 7.3.5；没有直接导入。
- **世界头顶气泡、过场字幕和第三方界面**未完整适配。NPC 聊天事件接入不等于这些位置同时生效。
- **随机宠物姓名**仍没有可靠中文映射，`Casketmasher` 保留原名。此前反馈的任务 26642《保卫贫瘠之地》完成对白、`HERETICS WILL BURN` 告示也继续保留原文，不能从相邻任务或字面含义生成“官方译文”。

## 核对与复现

- [任务扩展审计](translation-extras-audit.json)：逐字段来源、build、语言、指纹和未采用原因；原始候选与输入哈希在 `data/translation-extras.json`。
- [任务对白审计](reviewed-quest-dialogue-audit.json)：筛查结果、显式上下文复核和最终选择。
- [客户端名称及说明审计](extra-client-data-audit.json)：三语 CSV 的版本、URL、SHA-256 和分项统计。
- [总数据审计](data-audit.json)：基础数据、书页和上下文统计；详细来源说明见 [SOURCES.md](../SOURCES.md)。

`npm run build` 校验固定输入后生成中文资源，`npm test` 检查匹配与切换行为，`npm run check` 检查 Lua 5.1 语法、TOC 及资源约束。自动验证不等于实际游戏验收，客户端检查步骤见 [CLIENT-CHECK.md](CLIENT-CHECK.md)。
