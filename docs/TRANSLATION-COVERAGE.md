## 仍缺可靠依据或不能安全展示的内容

- **征令板的顶部文字、地区正文、除已核实通用界面文字外的按钮，以及卫兵指路的 `Orgrimmar Portals` 标签**仍缺可靠旧版中文对应；不采用人工译文或措辞已变化的新版记录。逐项说明见 [地图与征令板核验](MAP-UI.md)。
- **45 个任务候选字段**没有通过上下文、目标顺序或变量解析检查；另有 **11 个字段**在采集时缺少可核对原文或 build。世界状态值、职业复数等未知标记不能通过删除占位符来处理，详见两个任务审计文件。
- **9 个任务的进行中对白**仍缺可安全配对的英文原文：27944、27949、27970、27978、28059、28130、28882、29351、29419。拥有中文候选不等于可以按任务 ID 强行覆盖当前内容。
- 原有静态规则排除的 45,185 条法术描述、23,060 条光环描述中，本版分别接入了 16,224 和 11,709 条受限数值模板，余下 **28,961 条法术描述、11,351 条光环描述、16 条副标题**仍缺可靠配对或可支持的格式。原因包括复杂公式、持续时间／条件标记、缺少英文对照及内嵌标记；这些数量不能全部视为正常玩家技能的漏译。动态模板被收录也不保证客户端每种数值格式都能命中。
- 原先 **118 个书页 ID**的正文有译文冲突，本次通过页链恢复其中可明确区分的内容。其余冲突、打开时不是第一页、第一页无法识别、服务器改动页序等情况仍保留原文。旧版本中缺少同版本原文或内容已改变的页面也不会强行加入。
- **神器选择正文仍不完整**：新找到的 26654 候选中，仅 6 段通过完整原文及语义核验。恢复德鲁伊和死亡骑士候选存在差异，萨满选项错误复制了圣骑士内容，部分职业的中文栏仍是英文。旧候选及后续 build（如 27602、27843）没有直接混入；逐条理由见 [神器核验记录](ARTIFACT-DATA.md)。
- **神器外观说明并非全部齐全**：引用的 208 个解锁条件中有 45 个没有可配对原文，外观组的 222 个 Description 字段均为空，继续保留客户端显示。880 个外观名是资源记录；原版色块并不单独显示每种配色名称，不能把资源数当作新增界面数量。特质动态公式未新增求值器。
- **气泡与字幕仍有边界**：只处理插件可访问的 NPC 气泡、原版头像对白和 NPC 说话事件生成的字幕；受保护框体、内嵌视频字幕、第三方界面及没有对应译文的对白保持原样。气泡没有发送者 GUID，近期有玩家说出相同文字时跳过，避免改写玩家内容。
- **随机宠物姓名**仍没有可靠中文映射，`Casketmasher` 保留原名。此前反馈的任务 26642《保卫贫瘠之地》完成对白、`HERETICS WILL BURN` 告示也继续保留原文，不能从相邻任务或字面含义生成“官方译文”。
