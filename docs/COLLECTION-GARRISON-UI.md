## 数据与接口依据

固定文字来源为本地 CASC 导出的 7.3.5.26972 中文，与同版英文及繁体核对后的 `data/local-client-735.json`。`sources.json.localClientSnapshot` 固定文件哈希，索引构建仍由 `scripts/local-client-data.mjs` 完成。玩具／外观物品名复用已有同版 `ItemNames`；追随者姓名复用原有可靠 NPC 名称库，其中包含社区保存记录。只有实例名、模板默认名和可靠译文能对应时才替换，不宣称全部姓名都已经有官中。

显示入口参考 [Gethe 保存的 7.3.5 界面源码](https://github.com/Gethe/wow-ui-source/tree/67ecbf5ce0e50cc7483c2295caecf410460f0994)。核对了玩具按物品 ID 显示、幻化模型与套装详情、考古页面字段、职业大厅按钮池，以及追随者和建筑排版所用的真实字段与调用顺序。40 份来源文件的 Git blob 和 SHA-256 保存在 [接口核对清单](collection-garrison-ui-audit.json)。未将这些原始文件、CSV、DB2 或工具放入插件包。

## 匹配和性能边界

- 固定文字使用所属范围的完整原文指纹，不对玩家文本作任意片段替换。同名冲突继续保留原文，已有中文不覆盖。
- 普通考古挖掘场使用世界地图延后写入的区域标签。只在原版写字时，核对鼠标当前指向的真实 `WorldMapFramePOI`、挖掘场类型及完整名称，再查 Profession 范围；不依赖此类标记并不存在的鼠标提示，也不新增地图更新轮询。
- 拼接内容只处理原版明确组成的片段：考古分类名后的碎片／稀有度、技能说明后的原有解锁提示，以及带原生格式的应对名称。实际数字、格式和附加文本保持原样；整段对不上就跳过。
- 追随者使用模板 ID，而非实例 GUID；从当前列表行、面板或提示字段读取当前对象。重用提示显示舰船时不能继承上一个追随者的翻译资格。
- 共享下拉按钮与鼠标提示只在已识别的原版菜单／调用内修改，不给共享字体对象挂长期的无条件替换函数。
- 新控件由原有加载／刷新事件登记。1.3.3 对已识别的原版池使用 `Acquire` 内的 `resetterFunc(pool, object)` 回调，在对象交给调用方前绑定新控件，并在安装时处理已有活动／闲置对象；复用对象沿用挂钩。其他兼容池在 `Acquire` 后发现对象，但只登记未见对象；显式刷新仍能修复子控件替换。不新增逐帧扫描，不调用研究、招募、派遣、购买或使用物品等动作。
- 职业大厅研究同时绑定实际按钮方法和鼠标脚本，处理界面提前加载时复制的 `OnEnter`，以及原版计时器直接调用该方法的刷新路径。
- 追随者的威胁／应对图标使用独立的 `GarrisonMissionMechanicTooltip` 与 `GarrisonMissionMechanicFollowerCounterTooltip`。名称和说明在原版测量高度前绑定，迟创建的说明补算高度差；技能／法术重定向仍由原版处理，不改共享提示里的玩家文字。
- 追随者技能名在 `SetFontObject` 后只为该绑定刚翻译的文字确认中文字体，保留原版字号和样式；换成未知文字时清除标记，中文客户端沿用原生字体。

## 回归与实机复测

运行 `node --test tests/collection-garrison.test.mjs`。用安装包中的真实中文串和分范围指纹构造小型资料集，验证简体、繁体、无译文、控件复用、迟加载、物品变体、共享菜单与提示复用、姓名保护、数字保持和首次中文换行的高度处理。高度测试验证更新顺序，不模拟真实字体像素。`LCN_UI_FEATURE_BASELINE=1` 可对比当前 Git HEAD 的旧运行代码；此选项供此次接入审查使用，提交后 HEAD 会变化。

`tests/collection-garrison-regression-fixture.lua` 另外模拟同版原生调用顺序：地图延后写字、威胁／应对专用提示、研究按钮复制方法及池复用、技能名写入后再设置字体对象。针对这四项修复新增 13 项回归测试；其中 8 项在修复前失败，保护行为的对照项通过。测试不依赖本地 `.cache` 或在线下载。

1.3.3 的 `tests/ui-fixes-fixture.lua` 进一步复现原版研究确认、对象池与小地图提示调用。新增 11 项测试验证配方名称／说明、带箭头的幻化物品名、研究确认费用与时间、区域提示、对象池闲置对象与兼容回退。连续获取 16 个原版新对象只登记 16 次，获取期间不遍历活动列表；这项计数不等同于实机 FPS 测量。征令板补绑定、没有 `GetText` 的原版说明控件和布告板名称另由对应测试文件覆盖。

进入实际 7.3.5 客户端后：

1. 完全退出游戏，替换整个插件目录，用 `/lcn about` 确认版本及更新记录。
2. 首次打开玩具箱、幻化套装与外观提示，再翻页、切换收藏状态和套装变体。检查名称与来源、长名称截断和文字换行；保存的配装名及搜索内容应保持原样。
3. 在考古窗口切换当前项目、已完成项目和分类筛选，查看世界地图上的挖掘场。检查背景介绍、碎片数、稀有度和筛选菜单显示正常；普通挖掘场应在地图区域标签上显示译名，移开鼠标或换到其他标记后不应残留。
4. 打开职业大厅研究，依次悬停可用、研究中和不可用项目，检查固定说明与实时费用、计时、状态。鼠标在研究中项目上停留数秒，倒计时更新后应继续显示中文；打开研究确认框时名称应有对应中文，费用和时间不变，可取消确认避免实际消费。不要用模拟测试结果替代这些显示验收。
5. 在追随者列表、详情、招募与技能浮动提示间切换，并悬停技能旁的威胁／应对图标。默认名称有可靠对应时应显示中文；玩家改名、舰船及无可靠对应者保持原样。特别检查长技能说明、解锁附加文字和提示框重用时的高度。使用外文 UI 且已有游戏中文字体资源时，检查技能名在界面排版后仍能显示中文。
6. 查看建筑列表、建筑详情和不同等级说明，再查看地块提示，确认造价、建造时间、升级条件及操作正常；提示被用来显示其他单位时不能继承建筑翻译。
7. 在专业窗口切换已收录的配方，检查名称和说明显示中文、数量和制作功能正常；服务器改动过的说明与已有中文保持原样。查看幻化同外观的其他物品行，确认箭头／占位图标保留且有可靠对应的完整物品名显示中文。

不同服务器的自定义文字、第三方替代窗口及缺少可靠译文的内容仍可能显示原文。自动化加载、资源和接口测试不能证明所有客户端的字体、排版与性能已经实机验收。
