## 匹配边界

- 原有译文优先；当前显示已有中文时不替换。未匹配或被服务器改过的完整原文保持原样。
- 任务与场景目标保留实时计数和完成标记；成就条件在原版计算宽高前替换，不绑定完成者名字。
- 地图地点只处理已核实的原版 POI 框体前两行，不覆盖奖励和计时。
- 专业来源保留原生颜色与图标；双方图标、玩家变量不一致，或含未知标记、公式、printf 占位符时排除。
- 物品通用文字只在能确认当前物品时处理，复用为单位或法术提示后不保留旧译文。沿用已有 0.1 秒补充检查，未新增逐帧全界面扫描。
- 不绑定可改名宠物、船只、玩家角色或玩家创建的队伍名称。字体沿用游戏中文字体。
- 收录资料与显示入口分开统计，不能把所有表字段都当作本版可见汉化。

## 工具兼容修复

1. 更新到固定 CascLib 提交，支持旧工具不认识的资源标记。
2. 配置文件明确使用只读访问与共享读取；补丁只修改工作目录缓存中的工具源码。
3. 关闭 CDN 缓存及本地文件缺失时的在线回退，缺文件就记录失败。
4. 将 `byte[]` 导出为数值数组，避免 .NET 默认生成 Base64；超过 JavaScript 安全整数范围的 64 位整数保存为十进制字符串，防止位掩码精度丢失。
5. 固定布局定义并逐文件验证哈希；无法解析的表记录原因，部分失败不计为成功。

来源版本固定在 `scripts/extract-client.ps1`；程序 SHA-256 在 `client-extractor-tools.json`，逐表结果在 `client-extraction-audit.json`。原始文件保存在工作目录的 `work/casc-client-check/verified-export/`，不随 Git 或 AddOns 分发。

## 复现

项目根目录需要 Git、.NET 8 SDK 和 Node.js。首次准备工具需要联网；读取客户端时不使用网络回退，输出目录必须位于客户端之外。

```powershell
./scripts/extract-client.ps1 `
  -ClientPath 'C:/Users/zzz/Downloads/World of Warcraft 7.3.5' `
  -OutputDirectory '.cache/client-735'
```

提取子集可添加 `-Tables 'Faction,SpellItemEnchantment'`。完整重建须使用完整提取结果。

按 `data/local-client-735.json` 的 `tables` 下载并校验同版 enUS / zhTW 对照，分别保存到两个目录，文件名为 `表名-7.3.5.26972-enUS.csv` / `表名-7.3.5.26972-zhTW.csv`，再采集快照：

```powershell
node scripts/local-client-data.mjs `
  '.cache/client-735' '.cache/client-enUS' `
  'data/local-client-735.json' '.cache/client-zhTW'
```

确认候选变化后，将快照 SHA-256 更新到 `sources.json.localClientSnapshot.sha256`；不能跳过哈希检查或只修改 build。运行 `npm run build`、`npm test`、`npm run check` 和 `./scripts/package.ps1`，然后按 `CLIENT-CHECK.md` 在实际客户端核验。

## 仍然缺失

任务全文、进行中／交付对白和书页主要由服务器发送。安装包里的少量 BroadcastText 已被既有库覆盖，不能替代完整服务器数据库。服务器自定义内容和空 WDB 缓存也不能补齐这些缺口。本次仍未找到可以采纳的 `Casketmasher` 姓名、征令板完整说明或 `Orgrimmar Portals` 旧版标签中文，继续保留原文。
