# 7.3.5 客户端验收

2026-10-17 收到 0.1.2+build.5 的实际客户端截图：介绍窗口、版本号、作者署名和反馈地址可见，插件开关显示已开启。同组截图显示《复活术的副作用》第一页和任务 12680「阿彻鲁斯战马」进行中对话仍为英文。

0.1.3 修复书籍、任务进度及问候窗口的 XML 事件挂钩，并导入缺失的任务进行中与交任务对话。自动化测试使用安装包中的真实资源及加载插件前已绑定的事件回调重现这两个案例。**修复后的实机显示与滚动仍待复测**；以下步骤不能由模拟测试代替。

优先复测：更新安装包、`/reload`，重新打开《复活术的副作用》并连续翻完三页（数据库页面 3226、3227、3228）；再次与骑手萨拉纳尔交谈，任务 12680 的进度文字应显示「你不想一直徒步行走，对吧?」，已有中文任务标题保持不变。这两处译文来自 7.3.5 社区资料，VerifiedBuild 为 0，尚未逐字核实为官中。

1. 停用其他文本替换插件后启用 TauriChinese，确认没有加载错误，中文字体正常。
2. 打开数据库已覆盖的英文任务（如 ID 40519、44663、47221），检查标题、正文、目标、滚动范围。切换任务后内容应随任务改变。
3. 打开已有中文的任务或 NPC 对话，检查文本保持原样。中文标题配英文正文时，正文应能单独汉化。
4. 使用中文角色名访问带姓名占位符的英文 NPC 对话，确认仍能命中，并显示正确姓名、职业、种族及性别。
5. 连续选择同一 NPC 的不同对话选项，确认不会把上一段译文带到下一段；未知或歧义内容应保留原文。
6. 测试有匹配数据的书页及翻页。可从 [book-provenance.json](book-provenance.json) 中选择 `englishMatched: true` 的记录，至少包含有采集标记的页面 ID 5231、5232、5299、5300、5301、5302、5304、5305，以及新增的旧世界书籍。这些是数据库页面 ID，并非书籍内显示的第几页。核对长篇内容的滚动、分页和已有中文保持原样。
7. 记录插件启用前后的加载时间和内存使用。本版扩充了全文匹配索引，模拟逻辑测试不能证明真实客户端加载性能。
8. 打开不在数据库中的书籍、任务和对话，确认它们继续显示原文。
9. 分别运行 `/tcn off` 和 `/tcn on` 后重新打开窗口，验证开关。
10. 在无本插件设置的新测试账号上，首次登录应默认开启并弹出介绍窗口。检查版本、作者署名和反馈地址；分别测试“知道了”、右上角关闭、Esc，以及选中网址后 Ctrl+C 复制。重新登录、切换角色及 `/reload` 后不应自动再弹；`/tcn about` 应能重新打开。
11. 旧版用户升级后应只自动弹一次介绍，原先关闭的汉化开关应继续保持关闭。检查窗口内容在常用分辨率及 UI 缩放下不被裁切。
12. 从 [book-provenance.json](book-provenance.json) 中选择 `locale: "zhTW"` 且 `englishMatched: true` 的书页，确认缺少可用简体时显示繁体；简繁都具备的内容仍应使用简体，原来就有繁体的内容保持原样。

1.1.5 已将 Lite 字体换成同系列完整版，并检查全部现有 Lua 文本中的汉字均有字形，包括任务 25170 的“抷”。上游译文未改写；实际客户端的字形和字号仍需检查。

## 1.1.4 修复复测

以下五类问题已用自动回归测试复现并修复。测试使用 Lua 模拟环境、原版 7.3.5 窗口行为以及安装包中的实际任务和对话资源，仍需在游戏中检查字体、滚动与布局。

1. 连续姓名、职业、种族和换行：任务 187「勇斗猛虎」正文中的种族、职业应完整显示；任务 683 进行中对话中的职业和姓名应连续显示，之后正常换行，不应出现残留的 `c`、`N` 或 `B`。
2. 中文客户端的动态称呼：检查法师训练师等包含职业称呼的英文对话；无论英文句子中显示的是「法师」还是「Mage」，有对应译文时都应命中。中文角色名、种族及繁体客户端的称呼也应正确处理，原有中文句子保持不变。
3. 任务标题状态：分别检查任务日志中的组队人数、色盲模式等级、显示任务 ID 的前缀，以及失败任务详情中的失败提示。翻译只替换任务名称，这些附加信息及颜色应保留；切换任务后不应沿用上一项的标题。
4. 完成目标：将已有译文的任务目标完成后，目标正文应继续显示中文，计数和客户端的「完成」提示保持原样。可检查「将米娜·泥爪带回她父亲身边」对应目标；没有译文的目标继续显示原文。
5. NPC 任务问候列表：找同时提供多个任务的 NPC，检查长中文标题换行后下一项、分隔线及可接任务区域是否跟随下移，末尾是否可滚动查看。重复打开不应使行高不断增加，关闭插件后应恢复原版行为。

## 1.1.5 完整检查修复复测

1. 任务 47589「正义之怒」等包含动态数量变量的字段：不能解析时尝试可用繁体译文，再保留原文，不应出现 `$1oa`、`$1i`、世界状态变量，也不能猜测数量。标题和其他可翻译字段继续独立处理。
2. 中文短句「人类。」「法师！」「小明……」保持原样；已有译文的 `Humans.` 对话在人类角色上也能翻译。仅夹有中文姓名的外语句子仍尝试匹配。
3. 法师角色的训练师对话 `Well met, $c. You want some advice? Befriend a mage! ...`：称呼与正文中的普通职业词应分别处理。遇到不同中文结果的歧义或过多候选时保留原文，避免错配或卡顿。
4. 任务日志展开列表：检查未完成目标的中文、计数，以及完成任务后的交付说明。多行目标应增加所属任务行高，下一任务随之下移；重复刷新不应不断变高。已有中文、隐藏行和无译文内容保持原样。
5. 追踪任务的勾选图标应紧接翻译后的标题；任务名称变长或变短时检查图标位置。保留等级、组队人数、任务 ID、失败提示和颜色，并复测上一节的长标题行高。
6. 打开任务 25170 检查「抷」字；英文客户端也应使用完整中文字体。更新时按 README 替换旧插件文件夹。
7. 关闭插件后重开上述界面，应恢复原文；更新不能覆盖之前保存的关闭设置或再次自动弹出已看过的介绍窗口。

报告问题时提供客户端 build、任务 ID（若有）、NPC 名称、原文截图及显示位置。无需提供登录信息或翻译 API 密钥。
