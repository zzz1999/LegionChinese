# 7.3.5 客户端验收

当前尚无实机验收记录。以下步骤需要在实际 Tauri 客户端完成，不能由模拟测试代替。

1. 停用其他文本替换插件后启用 TauriChinese，确认没有加载错误，中文字体正常。
2. 打开数据库已覆盖的英文任务（如 ID 40519、44663、47221），检查标题、正文、目标、滚动范围。切换任务后内容应随任务改变。
3. 打开已有中文的任务或 NPC 对话，检查文本保持原样。中文标题配英文正文时，正文应能单独汉化。
4. 使用中文角色名访问带姓名占位符的英文 NPC 对话，确认仍能命中，并显示正确姓名、职业、种族及性别。
5. 连续选择同一 NPC 的不同对话选项，确认不会把上一段译文带到下一段；未知或歧义内容应保留原文。
6. 测试有匹配数据的书页及翻页。可从 [book-provenance.json](book-provenance.json) 中选择 `englishMatched: true` 的记录，至少包含有采集标记的页面 ID 5231、5232、5299、5300、5301、5302、5304、5305，以及新增的旧世界书籍。这些是数据库页面 ID，并非书籍内显示的第几页。核对长篇内容的滚动、分页和已有中文保持原样。
7. 记录插件启用前后的加载时间和内存使用。本版扩充了全文匹配索引，模拟逻辑测试不能证明真实客户端加载性能。
8. 打开不在数据库中的书籍、任务和对话，确认它们继续显示原文。
9. 分别运行 `/tcn off` 和 `/tcn on` 后重新打开窗口，验证开关。
10. 在无本插件设置的新测试账号上，首次登录应默认开启并弹出介绍窗口。检查版本、作者署名和反馈地址；分别测试“知道了”、右上角关闭、Esc，以及选中网址后 Ctrl+C 复制。重新登录、切换角色及 `/reload` 后不应自动再弹；`/tcn about` 应能重新打开。
11. 旧版用户升级后应只自动弹一次介绍，原先关闭的汉化开关应继续保持关闭。检查窗口内容在常用分辨率及 UI 缩放下不被裁切。
12. 从 [book-provenance.json](book-provenance.json) 中选择 `locale: "zhTW"` 且 `englishMatched: true` 的书页，确认缺少可用简体时显示繁体；简繁都具备的内容仍应使用简体，原来就有繁体的内容保持原样。

当前字体检查发现既有任务 25170 的目标含罕见字“抷”，内置 Lite 字体缺少该字形；新增繁体资源未引入其他汉字缺字。此项应在实机字体验收中记录，不改写上游译文。

报告问题时提供客户端 build、任务 ID（若有）、NPC 名称、原文截图及显示位置。无需提供登录信息或翻译 API 密钥。
